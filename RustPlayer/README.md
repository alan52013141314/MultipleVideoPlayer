# MultipleVideoPlayer Rust

Windows 10／11 x64 原生播放器。主程式和介面使用 Rust／egui，播放採用 libmpv，精準逐格索引由原生 FFmpeg 解碼產生，不需要 Python、Qt 或已安裝 VLC。

## 使用

完整解壓免安裝 ZIP，執行 `MultipleVideoPlayer.exe`，保留 `runtime` 和 `licenses`。設定保存到旁邊的 `portable_data`；專案的 `VideoPlayer/Start-Player.cmd` 沿用既有設定位置。影片只保存路徑，不複製到 preset。

拖入影片或資料夾，每個來源佔一格；資料夾包含子目錄並自然排序。右鍵格子可調整跨格、開檔、清空或移除。滑鼠移入格子顯示控制列；窄格使用「更多」。播放旁的音量按鈕展開各格獨立音量。

- 單擊影片畫面切換播放／暫停（等待約 0.3 秒辨別雙擊）；雙擊該格全螢幕，再雙擊或 Esc 還原，保持播放狀態。
- 全部播放／全部暫停：任何一格暫停時全部播放，所有影片播放中時全部暫停。
- 上方「全域畫面」與各格「畫面」可調亮度、對比、飽和度、Gamma、色相；範圍 -100 至 100，0 為中性。每格每項可取消「沿用全域」來覆寫。重置個別格會設為原始畫面；「全部恢復沿用」回到全域設定。隨 preset 保存，換片仍保留該格設定。
- 六種顯示模式；滾輪以游標為中心縮放，中鍵平移。倍率與中心隨 preset 保存。
- 時間軸可點擊及持續拖曳；A 在軸上方、B 在下方，可拖動；點 AB 數字直接輸入秒數與小數。
- 跳出 AB 區間會暫停循環；「回A」回到 A，保留播放／暫停狀態。
- 左右鍵控制最後懸停格，秒數可在上方設定；編輯欄位時不攔截方向鍵。
- 暫停逐格使用解碼影格索引。首次逐格在背景建立索引，長影片需要等待；換片取消舊索引，手動跳轉取消待執行步進。首尾不繞回。
- 放大格只改變檢視；Esc 返回網格，F11 全螢幕。
- 正常關閉保存上一次，重開恢復並暫停；損壞的上一次檔案不會被自動覆寫。

## 建置與驗證

需要 Rust MSVC 工具鏈與 Visual Studio C++ Build Tools。執行 `build.ps1`；腳本取得固定版本原生元件、核對 SHA-256，產生免安裝資料夾與 ZIP。`-Install` 切換專案入口，保留既有設定。

```powershell
cargo test --locked --bin multiple-video-player
.\build.ps1
```

`cargo run --release --bin verify -- <320x180測試影片> <報告.json>` 使用兩個實際播放器，檢查獨立音量、暫停狀態及各影格的正反向定位；GPU 讀回影像與 FFmpeg 逐幀參考影像比對。測試輸出不納入 Git。

舊 Python 原始碼留在 `VideoPlayer/src` 作為歷史與相容性參考，Rust 版不執行或封裝它。GPL 與第三方來源見根目錄授權說明。未宣稱在所有 Windows 10 顯示卡或任意十二條 4K 影片上流暢。

效能回歸：
`cargo run --release --bin seek_perf -- <至少18秒測試影片> <報告.json>` 在四格播放時反覆跳轉一格，記錄 GUI 間隔、其他格進度及最後跳轉位置；見 PR-011。
