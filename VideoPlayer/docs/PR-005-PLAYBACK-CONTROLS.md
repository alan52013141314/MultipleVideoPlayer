# PR-005：區間循環、每格音量及時間軸點擊

狀態：小型音量控制、點擊時間軸及版本標題已完成；`0.5.5-local2` 已安裝並更新正式入口，需正常關閉現有舊視窗後再啟動。循環問題依使用者要求延期。日期：2026-09-30。

後續修訂：使用者回報啟動入口仍為舊版，並要求在視窗標題附上版本。R5 工作計劃：以同一版本常數產生標題與 ZIP 名稱；將新版安裝至獨立資料夾，更新啟動指向；沿用原設定位置，檢查入口、套件與已安裝程式一致。此版為 `0.5.5-local2`。

## 需求與驗收

1. 循環停頓：使用者後續明確要求暫時跳過，本輪不修改循環行為。保留量測，另次處理；不宣稱停頓已消除。
2. 音量修訂：使用者確認音量控制已找到，改要求縮成播放按鈕旁的小型控制，不佔常駐整行。點開可調滑桿／百分比／靜音，仍為每格獨立。
3. 點擊時間軸任意位置即跳至對應時間，原有拖曳保留；點擊／拖曳不得改變其他格或意外切換播放狀態。
4. 原有 Start-Player.cmd 啟動最新版，視窗標題顯示明確版本；保留現有 preset，舊視窗未關閉時提示先正常關閉以保存設定。

## 工作計劃

啟動失敗後續修正（2026-09-30）：使用者回報雙擊無法開啟，實際原檔重現退出碼 255／`ayerRelease` 指令不存在。計劃：讓入口測試保留原始位元組及換行，先重現失敗；逐項排除換行、編碼及版本路徑，再修正原檔；最後以正式入口實際啟動確認，不以測試替身成功代替。

修正已完成：原 CMD 為 LF 換行，切換字碼頁後被 Windows 誤讀；僅改為 CRLF 即可正常執行。舊測試的文字讀寫會自動轉成 CRLF，掩蓋原檔問題；現改用位元組讀寫，已確認修正前重現同一錯誤、修正後通過。正式 Start-Player.cmd 已成功啟動已安裝程式，視窗標題包含 0.5.5-local2 且正常回應，證據位於 verification/launcher-real-start.json。播放器本體未變，版本維持 local2。

## 重現與發現

- 原生 QSlider 的一般 groove 點擊只做 pageStep：75% 處點擊從 10% 變成 10.1%，沒有 sliderReleased，因此未觸發跳轉。
- 260px 窄格內音量滑桿原本只剩 29px；使用者確認已找到控制，最終改為按鈕旁的彈出音量控制。
- 原循環一秒區間的實際回跳週期為 1257–1521ms，平均 1324ms。另以 libVLC 解碼回呼測試，畫面更新最大間隔約 35ms，未重現使用者的可見停頓。两類量測不可混為一談；原素材與切點未取得，循環按使用者要求延期。

- verification/controls-widget-verification.json：260/415px 控制列內音量只有按鈕；彈出框不在影片或控制列布局中；時間軸每次點擊只提交一次。
