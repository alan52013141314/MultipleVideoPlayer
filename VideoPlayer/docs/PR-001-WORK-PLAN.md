# PR-001 工作計劃：改造 GridPlayer v0.5.5

實作及打包已完成；最新控制列需求見 [PR-002](PR-002-HOVER-CONTROLS.md)。

狀態：P0–P3 已完成；P4 自動化短測與解壓啟動通過，最後原生桌面目視驗收待確認。詳見 [驗收紀錄](../../docs/VERIFICATION.md)。

## 核心規則

以 v0.5.5 原始碼為改造基底，沿用既有播放與打包架構，一次完成一個目標。不另開 WPF／libmpv 重寫分支，不因改造有難度就自行換基底。

需求維持：預設6格、最多12格、矩形跨列／跨欄、每格timebar與播放控制、來源資料夾前後條、各格獨立聲音＋一鍵全靜音、每個preset內各格只保存當前影片marker、可存多個自訂preset、關閉覆蓋「上一次」、無邊框／全螢幕獨立選項。

## P0：建立基準

已取得 [v0.5.5 原始碼](https://github.com/vzhd1701/gridplayer/tree/v0.5.5) 並記錄commit，依該版本依賴和打包說明建立本機流程；官方win64 portable用作對照。核對已存在的功能，只實作需求缺口。這一步不再重新選播放器或重寫技術。

完成條件：原始版本可啟動，改造與打包入口明確，列出對應PR需求的待改項目。

## P1：布局及窗口

保留既有播放器實例，加入預設六格、最多十二格與矩形跨列／跨欄操作。無邊框與全螢幕可分別切換，離開全螢幕回復合理視窗狀態。

驗證：六格及十二格布局各看一次，橫跨／縱跨各操作一次，窗口選項各切換一次。使用這台電腦目前的顯示縮放，不要求大量窗口切換或多DPI矩陣。

## P2：每格操作

補齊timebar、上一條／播放暫停／下一條、head／tail／clear及拖放；前後影片取該格來源資料夾。每格聲音獨立，一鍵全靜音不覆寫個別音量。換片清除舊marker，避免過期事件作用到新影片。

驗證：必要按鈕各快速操作一次；兩個格子使用不同資料夾確認互不影響。換片次數可計入P4的總共5次，不另加一輪。

## P3：多preset與關閉自動保存

沿用並擴充v0.5.5保存機制，加入preset選取／載入、另存名稱、明確保存到選定項目，以及固定「上一次」。每份preset保存當時的各格目前影片、marker、布局及既定參數；同片不同格或不同preset可有不同區間，不建立自動影片marker歷史庫。

關閉時先擷取目前狀態，再覆蓋「上一次」，最後釋放播放資源。載入自訂preset後的播放、換片、marker變動不自動回寫原preset；只有手動保存到該名稱才更新。即使目前從自訂preset載入，關閉也仍只寫「上一次」。

簡單驗證：保存兩份不同內容的自訂preset，切換載入各確認一次；在已有舊「上一次」的情況下，用新的目前狀態關閉重開，確認「上一次」已覆蓋、兩份自訂preset仍保持原內容。另存／載入可與既有功能檢查一起完成，不另加播放時數或換片次數。不要求全面損毀／中止注入測試。

## P4：簡化驗收與交付

以實際常用影片載入十二格，播放1分鐘，期間或之後總共換片5次；不是每格各5次，也不另做長時間壓測。必要控制、布局與保存檢查可沿用P1–P3的結果，不重複跑多輪。

簡單記錄開始／結束的總記憶體觀察，有明顯卡頓、崩潰或資源異常才針對原因調整；不設p95、固定掉幀比例或精密RAM數值門檻。修正實際問題後只重看受影響項目。

將改造版打包成Windows免安裝ZIP，從解壓資料夾啟動一次，確認所需相依元件與設定位置。保留版本和簡短測試結果即可。
