# PR-008：精簡控制列、AB 編輯、視圖縮放及精準逐格

日期：2026-10-04。目標版本：0.5.5-local4。狀態：完成。

## 已確認需求

- 目前／總長度、AB 時間、區間長度及回到循環合併單行。窄格縮短文字，完整時間放懸停提示，不換行。
- 時間軸顯示 A／B 及區間；A 在上、B 在下，可直接拖動，不與中間播放滑塊混淆。不允許 A 越過 B。
- 每格游標定點滾輪縮放，每格獨立，刻度 ×1.1／÷1.1，所選模式的 1–8 倍；顯示倍率及重置視圖。控制列上的滾輪保留原操作。
- 以游標下的影片內容為錨點，遇邊界才必要移位。黑邊以最近影片邊緣為錨點，中鍵仍可平移。
- 縮放和平移隨 preset／上一次保存；以正規化視圖中心保存平移，適應不同窗口尺寸。一般換片／換模式重置；載入 preset 還原其視圖。自訂 preset 只有明確更新才覆寫。
- 暫停時精準逐格前進／後退：使用者選擇新增解碼與實際影格時間索引，拒絕平均幀率推算。
- 可直接輸入 AB 時間（秒，小數精確到毫秒），顯示區間長度，驗證 0 ≤ A < B ≤ 影片長度。
- 單格放大查看／返回原網格；保持同一播放器及其他格的播放狀態。Esc 優先返回網格，暫時單格查看不保存到 preset。
- 不加入多格同步及其他未選功能；先前無縫 AB 效能優化仍暫緩。不建立伺服器。

## 實作要點

- `workspace_window.py` 負責控制行、AB 輸入、單格查看及背景解碼工作；`marker_slider.py` 分離播放滑塊與 A／B 標記。
- `Video.scale` 沿用為縮放值，避免相乘兩套倍率；`CellState.view_center` 為正規化中心，舊 preset 預設置中。
- `video_frame_vlc_base.py` 以完整影片表面加裁切處理縮放；保持先前六種畫面模式。
- `frame_step.py` 以 PyAV 16.0.1 從之前的 keyframe 解碼局部 PTS 序列，取得真正相鄰的影格；不在開檔時掃描整部影片，不用 FPS 推算。稀疏影格必要時退回起點解碼。
- 暫停逐格時顯示精確解碼影像，並同步 VLC 定位；回復播放／一般定位時退出影格檢視。首尾停在合法影格，不繞回；未能解碼會提示，不能靜默退成近似逐格。
- 解碼在背景執行，換片、手動定位及關閉會使舊請求失效；每格同時只處理一次逐格請求。
- `⋯` 提供上一格／下一格及 AB 時間輸入，`⛶` 單格查看，`↺` 重置視圖；不因新增功能增加常駐按鈕行。
- 新增元件的署名、授權及 FFmpeg build 資料隨包保留；原始碼與本地免安裝包分別交付。
