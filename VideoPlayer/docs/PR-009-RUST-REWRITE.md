## 啟動實測與限制

同一電腦空工作區，以程序啟動到視窗句柄出現比較：舊版第一次 12,114 ms、第二次 1,508 ms；Rust 326 ms。這是少量樣本，不能視為所有電腦的冷啟動保證。Rust 內部量測空視窗 266 ms；12 格測試 preset 的視窗 384 ms、第一格首幀 617 ms。未取得相同條件的舊版首幀數據，因此不宣稱首幀提升倍數。獨立解壓包另一次空視窗量測為 628 ms。

首次要求逐格需要完整背景解碼建立索引，長影片會等待；不唯一或逆序的顯示時間戳會報錯，不偷偷降級為估算。未在獨立 Windows 10 電腦或所有顯示卡上驗證；播放仍需要正常顯示驅動。AB 無縫回跳仍按使用者先前決定延期。
