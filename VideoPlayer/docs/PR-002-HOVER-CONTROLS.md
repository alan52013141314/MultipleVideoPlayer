# PR-002：滑鼠所在格子的覆蓋式控制列

日期：2026-09-30。狀態：實作、操作測試及打包完成；原生桌面目視驗收待確認。本文件取代 PR-001 的「控制列常駐」決策；其他需求維持。

## 需求

1. 滑鼠不在該格時，隱藏該格按鈕、標題／布局操作、時間軸、音量及標記資訊。
2. 滑鼠移入才顯示該格控制；在控制本身移動、拖曳時間軸或選擇跨格布局時仍能操作。
3. 影片一直佔用完整格子；控制列顯示時覆蓋影片，不預留高度、不擠壓、移動或重新縮放影片。
4. 只有所在格顯示；跨格、捲動、調整窗口、無邊框及全螢幕後位置仍正確；切換其他程式時不留下浮動控制。
5. 更新免安裝版和操作文件；繼續完成前輪尚未完成的 preset 與播放器打包驗收。
