# PR-007：鍵盤定位、時間軸、區間循環、影片平移及免安裝包

日期：2026-10-04。目標版本：0.5.5-local3。狀態：完成。

## 已確認需求

- 左右鍵控制最後滑鼠所在格，沒有紀錄時第一格。X 預設 5 秒，可設定小數並保存。輸入欄位編輯時不攔截左右鍵。
- 時間軸懸停顯示按下後的時間（毫秒）；滑塊與軌道都可持續拖動至放開，拖出格子仍可完成操作。
- 滑鼠或鍵盤定位到 AB 外時保留標記但暫停循環；定位在區間內繼續循環。「回到循環 / Back to looping」回到 A，保持原播放／暫停狀態。
- 中鍵拖曳被裁切的影片，限制在可裁切範圍；換片或切換模式重置位置。
- Windows 10／11 x64 資料夾免安裝包：解壓完整資料夾後直接點 exe，不需安裝 Python 或 VLC，保留旁邊元件。不承諾所有 OS 或所有顯示卡均可執行。

## 工作計劃

| 目標 | 狀態 | 驗證 |
|---|---|---|
| 1 時間軸與循環狀態 | 完成 | Qt/VLC 整合與打包版桌面點擊、拖動、區間內外定位、恢復且保留暫停 |
| 2 鍵盤目標格與步長保存 | 完成 | 焦點、最後懸停、第一格後備、邊界及小數；打包版右鍵跳轉 |
| 3 中鍵平移 | 完成 | 六模式幾何、裁切邊界；真實 Qt/VLC 中鍵事件、模式重置；原生畫面可見 |
| 4 portable exe 打包 | 完成 | 新路徑解壓、乾淨設定、直接 exe 啟動、正常退出及恢復；1358 檔案一致 |

只修改本次控制與交付功能；先前的無縫 AB 循環效能優化不在本次範圍。測試產物仍排除於 Git，保留上游署名及授權。

## 驗證結果

- 27 項資料／Qt 元件測試通過；`interaction_verify.py` 硬體與軟體解碼均通過，含初始化途中換片回歸測試。
- 驗收中修正 QStackedLayout 移除原生影片表面後將其隱藏的問題，及播放器清理後遲到的非同步載入回呼。回呼不再存取已釋放的 VLC 物件。
- Windows 11 x64 本機將 ZIP 解壓到含空白的新路徑；清除 Python/VLC 環境覆寫，PATH 僅保留 Windows 系統目錄。直接開 exe，可見影片、暫停、點擊／拖曳時間軸、設定 AB、離開／回到循環、方向鍵跳轉均經桌面操作確認。
- 正常退出後，分別驗證恢復設定加指定影片啟動，以及不帶參數直接啟動恢復並暫停；未再出現崩潰。建置、ZIP 與安裝副本共 1358 個檔案雜湊一致，入口驗證通過。
- 本次未使用獨立 Windows 10 電腦或乾淨虛擬機；Windows 10 相容性為套件目標，非跨機實測保證。中鍵平移使用 Qt/VLC 整合事件驗證，桌面工具不支援持續按住中鍵拖動。軟體解碼測試結束清理時曾輸出解碼器警告，未影響斷言或正常退出。
