# PR-004：拖入資料夾建立播放清單

日期：2026-09-30。狀態：範圍已確認，實作中。此 PR 取代先前的「首尾不繞回」。

## 需求

- 除影片檔案外，也接受資料夾拖放，找出影片、自然排序並播放第一條。
- 上一條／下一條依此清單切換；到尾端回到第一條，第一條往前回到最後一條。
- 每格清單獨立，保留既有每格音量及畫面模式。

## 一次確認的細節

使用者選擇「影片檔與資料夾清單都首尾循環」。其餘沿用已提出規則：資料夾包含子資料夾、依相對路徑自然排序、每資料夾佔一格；直接拖影片取同層影片清單。清單保存排序快照，重新拖入資料夾才重新掃描。空資料夾或掃描失敗會提示並保留原影片。
