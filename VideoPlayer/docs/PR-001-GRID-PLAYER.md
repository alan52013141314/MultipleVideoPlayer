最新修訂：控制列按 [PR-002](PR-002-HOVER-CONTROLS.md) 懸停覆蓋顯示；[PR-003](PR-003-CELL-DISPLAY-AUDIO.md) 加入六種畫面模式及明確音量百分比；[PR-004](PR-004-FOLDER-PLAYLIST.md) 加入資料夾遞迴清單，影片檔與資料夾均雙向首尾循環，取代本文早期的不循環規則。

日期：2026-09-30。狀態：已完成 GridPlayer v0.5.5 改造與打包，原生畫面目視驗收待確認。結果見 [驗收紀錄](../../docs/VERIFICATION.md)。

## 目的

在同一視窗內播放多條本機影片，每格能獨立操作與設定頭尾循環區間，並可將目前影片與播放參數保存為不同preset；每次正常關閉時自動覆蓋「上一次」。

## 需要使用者定義

主要問題均已回答，見 [決策紀錄與細節建議](../../docs/OPEN-QUESTIONS.md)。剩餘為資料夾排序／首尾行為、拖放多檔政策、控制列呈現、自動恢復是否立即播放，以及真實影片規格。這些建議須在實作前明示，不偷偷增加功能。

已確認使用目前電腦、自用、免安裝。矩形跨格與更自由布局都可接受，因此第一版規劃較直接的矩形跨列／跨欄，不把自由形狀及重疊當必需加項。

## 建議行為契約（待確認）

- 合法區間為 `0 ≤ head < tail ≤ duration`；未齊兩端不啟用區間循環。反向或零長度區間需說明，不能形成不停 seek 的忙迴圈。
- 以媒體時間 `[head, tail)` 表達區間。簡單確認能在指定區間回跳，不設定無縫或影格精準的多格 loop 數值門檻。
- 清除 marker 不刪影片，亦不清空清單。切換影片要防止前一條的 seek／事件誤套到下一條。
- 資料夾候選規則：同層可播放檔案自然排序；切換時更新；到首尾停住而不繞回。一次拖入單檔到指定格直接播放；多檔分配格子的規則留待操作樣稿確認，不自動建立新類型播放清單。
- 每格換片時清空目前工作狀態的舊marker；同一影片在兩格仍可設定不同區間。已手動保存的preset保持原快照，換片不會回寫或刪除其中的marker。
- 各格音量／靜音獨立；一鍵全靜音用額外的全域開關，不把原有各格數值覆寫成零。
- 矩形布局以格子位置及跨列、跨欄描述，禁止意外重疊。改布局時優先重用原播放實例，避免全部重新開檔。
- 增格不等於無限解碼。已驗證工作負載外要明確顯示限制；未獲同意不可偷偷把其他格暫停或降解析度。

## Preset保存規則（已確認）

1. **多個preset**：可將目前整個播放器狀態保存為自訂名稱的preset，並選擇任一已存preset載入。
2. **手動另存／更新**：可另存成新名稱，或明確選擇既有preset作保存目標。保存內容是當下狀態的獨立快照，不是持續跟著播放狀態變動的參照。
3. **「上一次」**：固定的自動保存preset。每次正常關閉程式時，把關閉前狀態寫入同一個「上一次」，覆蓋前一份；不累積多份自動歷史。
4. **自訂preset不被連帶覆蓋**：即使從「練習A」載入後改了影片或marker，關閉時也只更新「上一次」。「練習A」只有使用者明確手動保存到它時才更新。
5. **保留某次狀態**：可把當前狀態或載入的「上一次」另存成任意自訂名稱。「上一次」作固定自動保存項，不再建立第二個同名自訂項。

例：保存「練習A」→改影片與marker→保存「練習B」→再調整後關閉。下次可選「練習A」、「練習B」或已更新的「上一次」，三者各自對應保存當時的狀態。

### 每個preset的內容

沿用本案既有保存範圍：格子識別、格數與布局、各格當前影片路徑與head／tail marker、窗口選項。每格只存當前那條影片，不自動收集所有看過影片的marker；不同preset可以各自保存不同影片，或同片的不同marker。

來源資料夾可由目前影片路徑推導，不需保存每格歷史清單。各格音量／靜音、全域靜音與播放位置仍列為建議附帶欄位；啟動時是否自動載入「上一次」及載入後是否立即播放仍待操作細節確認。這不影響已確定的關閉自動保存規則。

### 內部保存設計

沿用GridPlayer既有影片／marker序列化並加入preset索引與版本資訊。自訂顯示名稱與內部識別分離，避免把任意名稱直接當成Windows檔案路徑。不同preset的資料互相隔離。

關閉順序：先擷取目前狀態，再安全寫入／替換「上一次」，完成後才停止播放及釋放資源；不可等播放器清空後才存成空白狀態。手動保存亦使用單一寫入序列和暫存替換，失敗時保留上一份有效資料並顯示結果。

影片搬移／刪除時保留preset內該項目與marker，指出缺失來源，不默認替換成另一條同名影片。來源已變更時重新驗證區間。載入或切換preset不直接修改其他已存preset，保存前的載入失敗不能以空白內容蓋掉它。

本版只簡單確認自訂preset、關閉覆蓋「上一次」及再載入；不增加長測或故障注入要求。

## 已選定改造方案

以 [GridPlayer v0.5.5](https://github.com/vzhd1701/gridplayer/releases/tag/v0.5.5) 對應原始碼為基礎改造，沿用既有 Python／PyQt5／libVLC 架構與打包方式，按本PR補齊需求。官方portable作操作對照；修改的是原始碼，之後重新打包成免安裝版。

不切換到 master／continuous，也不另起 WPF 或 libmpv 重寫。若選定基底遇到無法解決的限制，列明問題後再由使用者決定路線；本計劃不預設改技術。

驗收按最新要求採1分鐘播放與總共5次換片。資源釋放、有界工作及原片／設定保護仍屬實作基本要求，但不設長時間壓測門檻。[研究與選型](../../docs/RESEARCH-AND-DECISION.md)

不自製解碼器。不新增串流服務、帳戶、遠端控制、下載影片、雲端同步、跨機同步或監控平台。同步播放、任意形狀及重疊只有在使用者確認後才納入。
