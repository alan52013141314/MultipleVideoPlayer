# PR-003：每格音量與六種畫面模式

日期：2026-09-30。狀態：實作中。延續 PR-002 懸停覆蓋控制。

## 已確認需求

- 每格可獨立調節音量，其他格不受影響；全域靜音保留個別設定。
- 每格獨立選擇六種畫面模式：Fit 完整顯示（允許黑邊）、Fill 等比例填滿（裁切）、符合格子寬度、符合格子高度、Stretch 拉伸填滿、原始像素 1:1。
- 前五種以格子尺寸為基準；1:1 為來源像素對顯示器實際像素，居中，較大時裁切，較小時黑邊。模式保存在 preset，換片沿用該格模式。
- 音量及畫面選項置於原有懸停控制層，不佔影片布局空間。
- 使用者已再次允許桌面工具操作；完成前輪原生畫面驗收。

## 發現

已有每格音量滑桿與獨立儲存，需改善可辨識度及複驗。上游 Video 已有 aspect_mode 欄位，沿用並擴充，不另建平行狀態系統。上游 FIT 實際代表填滿裁切、NONE 代表完整顯示；介面以清楚中文及 Fit／Fill 標示，保存值保持相容。
