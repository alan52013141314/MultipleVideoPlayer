# PR-010：點擊播放、全域播放與畫面調整

狀態：0.6.1 已完成並安裝，更新至 GitHub PR #1（未合併）。日期：2026-11-07。

## 已提出需求

- 點擊影片畫面可直接播放。
- 加入全域播放按鈕。
- 全域與個別格子都有畫面設定（亮度、對比等），個別設定優先於全域。
- 雙擊影片畫面讓該格全螢幕，再雙擊還原。

## 已確認操作

1. 單擊切換播放／暫停；全域在部分暫停時全部播放、全部播放中時全部暫停；雙擊保持原播放狀態。
2. 調整項目為亮度、對比、飽和度、Gamma、色相；逐項繼承／覆寫、重置，隨 preset 保存。

## 現況

Rust 0.6.0 已提供各格播放按鈕、單格放大及整個視窗全螢幕，但畫面單擊／雙擊尚未綁定。每格已有獨立 libmpv 實例，可對各格套用畫面參數；Workspace／Cell 需要新增有預設值的欄位以保持舊 preset 相容。

同一時間只推進一個主要目標。

| 目標 | 狀態 | 驗證 |
|---|---|---|

| 3. 畫面設定與 preset | 完成 | 全域傳播、個別覆寫、恢復繼承、重置、換片與舊 preset 相容 |

## 實作注意

- 單擊與雙擊需區分，雙擊不可先觸發兩次播放操作。
- 進入單格全螢幕前保留視窗全螢幕及單格放大狀態；還原不改變其他格播放。
- 畫面參數只影響播放顯示，不修改影片檔案。
- 沒有影片的格子不參與全域播放狀態判斷。
- 舊 preset 缺少畫面設定時使用正常中性顯示。
- 不加入其他功能或伺服器；不改變先前延期的無縫 AB 循環範圍。

交付：VideoPlayer/Start-Player.cmd 已指向 MultipleVideoPlayer-0.6.1；免安裝包位於 RustPlayer/dist/MultipleVideoPlayer-0.6.1-win64.zip。


## 驗收紀錄

- 10 個單元測試通過：新增逐項繼承／覆寫、JSON 保存還原、舊 preset 中性預設、非法範圍拒絕。
- 主程式 Clippy 警告視為錯誤檢查通過；Rust 格式檢查通過。
- 原生整合驗收共 83 項通過：既有 VFR 精準逐格及獨立音量，另加五項畫面參數改變／重置的 GPU 像素比對。每項改變均有可測量差異；重置後與原畫面差異為 0，另一格差異始終為 0。
- 桌面實測單擊播放及暫停、全域播放／暫停；暫停在 10.167 秒時雙擊全螢幕再雙擊還原，影格保持 10.167 秒。原視窗 1280×800 與位置保留。
- 全域亮度調至 42 時兩格均變亮；第一格覆寫為 -15 後第二格保持全域亮度。關閉保存後 JSON 確認全域 42、第一格僅亮度 -15、其餘欄位繼承、第二格全部繼承。
- 重開正式 0.6.1 後畫面設定恢復正確；「全部恢復沿用」讓第一格重新跟隨全域，「重置為原始畫面」只讓第一格回到中性，第二格保持全域值。
- 所有桌面驗收使用 verification 下的隔離測試 preset，未修改使用者工作區。

畫面參數沿用 [mpv 官方手冊](https://mpv.io/manual/stable/) 定義，作用於播放顯示，不改寫影片。雙擊全螢幕狀態不作為持久視圖保存；關閉時保留進入前的視窗全螢幕狀態。
